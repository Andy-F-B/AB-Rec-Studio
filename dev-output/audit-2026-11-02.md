## High

**H1. Placeholder content is still live.** There are 16 TODOs in content/ and app/: placeholder musicians, festival name, date (June 12, 2027 is a guess), venue, description, the studio story, and the address/socials. *Fix:* fill in content/*.ts.

**H2. Two festival FAQ answers are TODO** (age limit, parking) in app/festival/page.tsx. *Fix:* give answers, or remove those questions.

## Medium

**M1. No error page.** There's no app/error.tsx, so an unexpected client error shows Next's default screen. Checklist "Error state implemented": FAIL. *Fix:* add a branded error.tsx.

**M2. Lineup times use the server's timezone.** On Vercel that's UTC. *Fix:* give performanceAt values with the festival's offset (e.g. 2027-06-12T18:00:00-05:00), and format with a fixed timeZone.

**M3. HSTS header includes `preload`.** That asks browsers to hard-code HTTPS for the whole domain and its subdomains, which is hard to undo. *Fix:* remove `preload` until the domain is final.

## Low

**L1. CSP allows `'unsafe-inline'` scripts.** This is required for a static Next.js site without nonces. The risk is low because there's no user input or third-party script.

**L2. Dev-only dependency advisory.** It's a moderate minimatch ReDoS in the ESLint toolchain. It isn't shipped to visitors, and production dependencies have 0 vulnerabilities.

**L3. Default Next.js favicon, no Open Graph image.** Shared links won't show studio branding. *Fix:* add app/icon.png and app/opengraph-image.png.

**L4. Unused dev dependency `@eslint/eslintrc`.** *Fix:* remove it from package.json.
